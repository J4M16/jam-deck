========================================
  Jam Deck v0.30.0 — 安装说明
  Obsidian 副屏工作台插件
========================================

【这是什么】
Jam Deck 是 Obsidian 的副屏工作台插件，提供时钟、日历、待办、
剪贴板、快捷方式、音乐播放器以及可实时编辑的内嵌 Canvas。
适合放在副屏或侧边栏，一眼看到时间、日程和待办。

【文件结构】
zip 解压后应有：
  manifest.json      插件清单（不要改名）
  main.js            插件主程序（不要改名）
  styles.css         样式文件（不要改名）
  assets/            资源目录（整个文件夹保留）
  本说明文件

【安装步骤（约 1 分钟）】
1. 解压本 zip，得到 jam-deck 文件夹内容。
2. 打开 Obsidian，进入 设置 → 第三方插件（社区插件）。
   - 如果顶部有「安全模式」，请先关闭它。
3. 点击「浏览」旁边的「文件夹图标」，选择「打开插件文件夹」
   （或手动进入：你的仓库目录/.obsidian/plugins/）。
4. 在 plugins 目录下新建文件夹，命名为 jam-deck，
   把解压出的所有文件（含 assets 文件夹）复制进去。
5. 回到 Obsidian：设置 → 第三方插件 → 插件列表里找到
   「Jam Deck」，打开开关启用。
   如果列表里没出现，重启一次 Obsidian 即可。

【怎么打开工作台】
方法一：点击左侧边栏的 Jam Deck 图标。
方法二：按 Ctrl+P 打开命令面板，输入「Jam Deck」，
        选择「打开 Jam Deck 工作台」。
方法三：右上角「添加组件」可自定义布局。

【AI 助手（可选）】
工作台右上角的 AI 按钮需要 API Key 才能对话：
设置 → 第三方插件 → Jam Deck → 填入 DeepSeek 或千问的 API Key。
不填不影响其他所有功能。

【卸载】
设置 → 第三方插件 → Jam Deck → 关闭开关；
再删除 plugins/jam-deck 文件夹即可。

【常见问题】
- 插件列表没有 Jam Deck：确认文件在
  <仓库>/.obsidian/plugins/jam-deck/ 下，且 manifest.json 直接在
  jam-deck 文件夹内（不要在子文件夹里）；然后重启 Obsidian。
- 启用后界面空白：按 Ctrl+Shift+I 打开开发者工具，看 Console
  有无红色报错，把报错截图反馈给作者。
