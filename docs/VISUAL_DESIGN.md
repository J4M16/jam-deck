# Spatial 白板视觉规范

## 核心语言

- 低对比浅灰点阵背景。
- 漂浮纸张、照片与柔和多层阴影。
- 黑白中性色为主，荧光绿和浅青只用于焦点、状态和错层底板。
- 暗色主题由 `.theme-dark .jam-deck-root` 自动启用。

## 全局动效语言

- Jam Deck 整体采用优雅、简洁、反馈清楚的动效。组件显隐、弹层进退、悬停、按下和状态切换都应有轻量、连贯的过渡；新增或修改交互必须同时设计出现与消失，不能只把元素突然开关。纸面与玻璃共用节奏，不为不同组件各造一套动画。
- 常规出现与消失使用 `--jd-motion-enter` / `--jd-motion-exit`（均约 300ms），透明度缓动共用 `--jd-motion-ease`。弹层与悬浮工具栏允许透明度配合轻微缩放，出现使用 `--jd-motion-spring` 的阻尼回弹，越过原尺寸的幅度控制在约 1% 内；消失平滑收拢，不重复弹跳、不夸张缩放、不循环装饰。参考 [Apple Animate with springs](https://developer.apple.com/videos/play/wwdc2023/10158/) 的阻尼与连续运动原则，当前 CSS 曲线为采样近似，不宣称复刻原生弹簧引擎。已登记的翻牌、FLIP、日结单叙事动效保留各自编排。
- 动效不能改变布局或命中语义。隐藏先关闭鼠标命中，淡出完成后再隐藏可见性；恢复时立即可操作。快速反向操作从当前画面接续，不排队、不闪回起点，不为了动画等待而拖延保存或导航。拖拽对象和键盘焦点不能在操作中被隐藏。
- 工作台动效遵循插件已有「动画效果」开关；关闭后直接到达最终状态。只在真实状态变化时播放，不因普通重绘重播；不添加逐帧 JS 循环，不动画大面积模糊半径。平台与系统开关的既有例外见各模块说明。
- Canvas 底部工具栏：闲置 5 秒后约 300ms 淡出并收至 94%，重新操作时约 300ms 淡入，从 94% 轻弹至约 100.7% 后稳定在 100%。以底部中心为支点，布局占位与原生定位保持稳定，使用独立 `scale`，不得覆盖 Obsidian 的定位 `transform`。验证必须覆盖缩放与透明度中间帧、回弹峰值、快速反向、关闭动画及键盘路径，不能只检查动画样式存在。

## 可选 Liquid Glass 皮肤

- 默认 Spatial 保留；玻璃仅在 `.jam-deck-root[data-jam-deck-skin="glass"]` 内启用，自有弹窗以对应 body 状态和专有类限定。
- 一个组件仍只有一个主表面，使用 18px 连续圆角、细高光、通透底色和柔和阴影；普通按钮共享所属表面，不新增逐行卡片或彩色胶囊。
- 设置提供「玻璃底色不透明度」0–100%，只调工作台组件与工具栏的下层填充，保留随壁纸明暗选择的原有颜色、文字、磨砂与高光。默认保留现有浅色 32% / 深色 48%，恢复默认回到该自适应值；实时预览不得重建组件、滤镜或背景媒体。
- 设置提供「文字与图标明暗」0–100%，50% 原样保持现有配色；高于 50% 按 `(值 - 50) × 2%` 混白，低于 50% 按 `(50 - 值) × 2%` 混黑。对玻璃工作台的主文字、次级文字、弱提示、标题及功能图标共用同一比例，壁纸切换明暗档后在新原色上继续混合；玻璃灵动岛使用同一设置。端点为纯黑/纯白，恢复原配色回到 50%。原生 Canvas 内容、网页、图片图标、状态色及独立底材的弹窗保持其原有配色；滑动只改颜色变量，不重建媒体或滤镜。
- 玻璃灵动岛的文字和图标独立于折射层。剪贴板条目、倒计时与恢复入口按各自下方桌面区域选择明暗配色，每秒一次缩略图采样并保留明暗缓冲区；文字滑杆继续作用于所选原色。细字允许轻微字边保护与柔和文字阴影，禁止因此增加实心条目底板或整岛白色填充。倒计时与剪贴板更新立即复用最近一次采样，不能闪回系统主题字色；采样源明确排除系统光标，真实指针不得再次作为模糊重影出现在材质下层。
- 每个工作台只有一个背景图片/视频。Canvas 背景透出是明确的皮肤例外：规则以 `.jam-deck-canvas-leaf` 开头并要求玻璃根祖先，只调整宿主、view-content、view-header、canvas-wrapper 与点阵背景，不改节点、命中或层级语义。
- 玻璃工作台按整张壁纸平均亮度自动选择配色：深背景浅字、亮背景深字，背景压暗也参与判断，不依赖 Obsidian 明暗主题。文字、图标、轻控件和内嵌 Canvas 工具栏同步适配，原生节点内容不改；自有弹窗有独立底材，继续随 Obsidian 主题。标题 `--jd-glass-heading` 是原固定 `#5c5c5c` 的限定例外，Spatial 固定标题色不变。
- 普通操作默认无底无阴影，悬停仅 6–8% 轻叠色；输入与播放等主操作保留低强度底色。倒计时输入及运行翻牌使用同一玻璃色系，内部分隔用 `--jd-line`，选中态用细线，键盘焦点保留明确细环。待办使用可见标题作为无障碍名称，避免重复黑色提示。
- 内嵌 Canvas 普通激活描边与静止细边同强度，不复用纸面的高亮青色；布局编辑与碰撞提示保留。Canvas 内容边界显式使用 `--text-normal`，与原生节点底色配对；玻璃工具栏独立使用壁纸配色，避免白底笔记继承浅色文字。
- 折射最多 4 个表面，单面 18 万/合计 36 万 CSS 像素；优先工作台与 Canvas 底栏，其他表面使用轻磨砂，不创建全屏滤镜。模糊 0–16px，默认 4px；Canvas 大表面使用一半强度的独立材质层，避免嵌套 backdrop 根截断底栏取样。没有逐帧 JS 动画循环，尺寸变化合并处理；亮度仅在图片解码后或视频播放时每秒读取一次 32×18 缩略图，暂停和隐藏停止，明暗判断保留缓冲区。
- 顶栏文字按钮（含「映画」背景入口）使用无底纯文字，悬停/活动状态也不加底板；Canvas 右侧只保留功能组底色，外壳透明，内部细分割线与外沿使用同一强度；原生底栏图标使用清晰线条，不填白底。清透材质参考 Glass-HQ 的方向高光收束：保持折射几何，减弱背光面反光；启用光学贴图的表面取消重复 CSS 内高光，轮廓使用 `--jd-glass-optical-line`，外阴影使用 `--jd-glass-depth-shadow`。普通表面沿用 `--jd-glass-shadow`，标题分隔统一使用 `--jd-line`；编辑、碰撞和拖动反馈优先。
- 纸面与玻璃共用侧栏/顶栏独立隐藏开关，仅活动工作台（包括内嵌 Canvas）生效。隐藏顶栏时连同最小化、最大化、关闭按钮一起隐藏，点击「恢复界面」后显示；不改原生侧栏折叠状态、不搬节点，切笔记与卸载恢复。
- 只有新增视频背景响应系统减少动态效果并暂停；既有组件动画继续遵循当前插件开关。切换皮肤不重建工作台，隐藏、灵动岛和关闭时暂停/释放媒体与光学资源。
- 实现取舍、设置说明及平台验收范围见 [GLASS_SKIN.md](GLASS_SKIN.md)。

## 新功能接入原则

- 一个模块只保留一个主表面；列表行、日历日期和普通状态不得再各自升级为厚卡片。
- 荧光绿只用于焦点、今天、活动任务点与完成量热度等状态，禁止作为整格、整行或大面积常态背景；完成量仅可填充日期按钮本身。
- 状态优先用 2–4px 小圆点、细环和文字层级表达，避免同时叠加边框、阴影、色块与胶囊；已完成日期热度是限定在日期按钮内的唯一分档色块例外。
- 日历日期默认无背景、无阴影、无常态边框；当天存在已完成或已归档待办时，日期按钮使用 7px 圆角品牌绿底板，1/2/3/4/5+ 项依次为 20%/40%/60%/80%/100% 透明度。
- 待办分类位于标题之前，以低对比文字前缀表达；不要放在标题下方形成第二行彩色标签。
- 列表行默认透明并使用轻分隔或留白，hover 只做低对比表面变化，不形成独立卡片墙。
- 新增功能前必须回看本文件与 Spatial 参考：先复用现有层级和 token，再决定是否增加新视觉元素。
- 窄组件优先减少装饰和次级文字，不缩小点击区，不破坏键盘焦点路径。

## 设计令牌

- 令牌的像素值与色值只有一个来源：`styles.css`。本文件与其他文档只引用令牌名，不重复写数值，避免两处各自漂移。
- 作用域：自有弹窗由 Obsidian Modal 挂载到 `document.body`，不在 `.jam-deck-root` 内。工作台与弹窗共用的令牌必须定义在 `styles.css` 顶部的 `body` 块，且该块只放跨明暗主题不变的值；随主题变化的令牌仍定义在 `.jam-deck-root` 与 `.theme-dark .jam-deck-root`。
- 圆角阶梯全部取双数：`--jd-radius-chip`（徽标、微控件、进度条）、`--jd-radius-control`（文本输入与按钮）、`--jd-radius-surface`（组件内小表面：卡片、行）、`--jd-radius-sm`（图标尺寸的方块）、`--jd-radius-md`（分组）、`--jd-radius-lg`（主表面与弹窗）、`--jd-radius-pill`。前三档是角色令牌而非尺寸档，同类元素无论出现在哪里都保持同一个圆角。新增圆角一律复用这七个令牌，不写字面像素值。
- 允许留在阶梯之外的只有三类，且必须在代码里注释说明：拟物与 Figma 几何（文件夹壳体前片与叠纸、唱机唱臂）、按盒子比例缩放的图标圆角、以及包裹某一档内容表面的外壳（玻璃弹窗外框比 18px 内容层大 4px，保证内外圆角同心）。
- 图标圆角是等比关系而非阶梯：快捷方式图标在不同尺寸下保持大致相同的圆角比例，使弹窗预览与工作台实物形状一致；这类比例值不纳入阶梯令牌，也不与之归并。
- `!important` 只用于「必须压过 Obsidian 主题」的基态。凡是自家皮肤层还会继续调的状态（尤其玻璃皮肤对危险色、悬停底色的定制）一律不加——皮肤规则特异性更高但通常不带 `!important`，一个多余的 `!important` 会把皮肤定制悄悄压掉。改这类规则前先搜一遍 `[data-jam-deck-skin="glass"]` 里有没有同名选择器。
- 给原生表单元素（`input` / `textarea` / `select` / `button`）写样式必须带上元素类型，例如 `input.jam-deck-countdown-duration`。Obsidian 主题自带的 `input[type="text"]` 特异性为 (0,1,1)，裸单类 (0,1,0) 会被它压过，结果是常态取主题的 `--input-radius`、而 `:focus` 等伪类态取自己的值，产生肉眼可见的跳变。
- 修改任何 `.jam-deck-*` 基础规则前，先确认是否存在 `.jam-deck-root .jam-deck-*` 的 Spatial 重写版本。扁平期遗留规则仍留在文件里，但特异性一律输给 root 版本；静态阅读会把僵尸规则误判为生效，结论以运行中 Obsidian 的计算样式为准。
- 判定僵尸不能只靠 grep 同名类的重写版本。基础规则还会被**更宽泛的 root 规则按顺序压过**——`.jam-deck-widget.is-editing` 与 `.jam-deck-root .jam-deck-widget` 同为 (0,2,0)，靠后的赢，而 grep 查不出这种关系。静态搜索只能当线索，判定一律以运行时计算样式为准。
- 勾选框不要靠 `accent-color`。Obsidian 自绘 checkbox：`appearance: none`，`:checked` 用 `background-color` 画底色、`::after` 用纯色方块配 SVG mask 画勾。`accent-color` 只作用于原生绘制的控件，对自绘控件**静默失效**——改了它计算值会如实变化，渲染却完全不看。要换色必须覆盖 `:checked` 的 `background-color` / `border-color` 与 `::after` 的 `background-color`；品牌绿上的勾必须用 `--jd-accent-ink`，白勾在 `--jd-accent` 上几乎不可见。覆盖选择器要逐个列举 Jam Deck 自有类名，不能用 `input[type="checkbox"]`，否则会命中内嵌 Canvas 笔记正文里的任务列表复选框。
- 由此推广一条验收纪律：**读真正参与渲染的属性，而不是读自己刚改的那个属性。** 已知三种「计算样式骗人」的形态——滚动条伪元素（`getComputedStyle` 返回值与渲染无关）、`dev:screenshot` 返回缓存帧、以及当前绘制模式下被忽略的属性（如自绘控件上的 `accent-color`）。
- `getComputedStyle` 返回的是**实时对象而非快照**：先读进变量、随后改了 class，那个变量会跟着一起变。要留快照必须当场 `String()` 取值。
- eval 里反复开关自有弹窗会累积孤儿 `.modal-container`，`querySelector` 会取到最早的残留节点，读出的状态完全不可信。取节点一律用 `querySelectorAll` 的最后一个，或先清掉全部 `.modal-container`。
- **窗口不在前台时 Chromium 会暂停 CSS 动画时间轴**（实测 `playState` 为 running 但 `currentTime` 始终为 0），与「后台窗口 rAF 不执行」同源。因此 agent 只能验证动画的绑定与参数，真实观感必须由 Jam 在前台确认，不要因为量不到就断言动画没生效。
- 更普适的一条：**先把用户描述的现象翻译成可测量的指标，再去测它**，不要测「自己刚改的那个量」。例：用户说「点勾后跳到顶」，要测的是滚动容器的 `scrollTop`，而不是行的索引或 `getBoundingClientRect().top`——列表停在顶部时后两者根本不会变化，测了会得出"已修复"的错误结论。
- **重绘后修正状态的逻辑不能依赖 `requestAnimationFrame`。** Electron 会暂停不可见窗口的 rAF（实测窗口在后台时 600ms 内一帧未触发），回调静默不执行。需要在重绘后还原滚动位置、尺寸等状态时，一律在整棵 DOM 构建完成后**同步**执行；读一次 `scrollHeight` 之类的属性即可强制布局，拿到最终值。
- 组件重绘会把 `.jam-deck-widget-body` **整个节点换掉**（不是复用），因此一切挂在该节点上的浏览器状态（滚动位置、焦点、选区）都会丢失。新增可滚动组件时记得接入 `restoreWidgetScrolls()` 的记忆机制。

## 字号与阅读密度

- Jam Deck 自有标题统一使用固定 `#5c5c5c`，包括工作台、组件与标题图标、AI 面板、日历、音乐、待办、快捷方式名称、弹窗、设置页及灵动岛品牌文字；明暗主题均保持该指定色值。仅作用于自有标题，不用通配标题选择器覆盖原生 Canvas、网页或笔记正文。
- 界面字号统一提供小 / 中 / 大，小档即插件早期的紧凑字号与布局；已有设置缺少字号时保持小档，新安装默认中档。
- Jam Deck 自有界面使用 `--jd-font-*` 语义字号，包括组件标题、正文、辅助信息、按钮、表单、弹窗与灵动岛文字；新增文本复用对应角色，不另写孤立字号。
- 字幕与跟读正文可跟随全局或独立选择小 / 中 / 大，分别为 17 / 20 / 24px。保持正文与时间戳、状态文字的层级。
- 中、大档让控件高度与必要间距随文字增长，窄窗换行；不得通过整页缩放、重建工作台或缩小命中区处理溢出。切换字号不打断现有组件会话。
- 图标、字符封面、时钟主数字保持原尺寸；原生 Canvas 内容与网页自身排版由对应视图管理，不受 Jam Deck 界面字号控制。样式只消费命名空间变量，不修改 Obsidian 全局字体。

## 滚动条

- Jam Deck 工作台与自有弹窗共用极细滚动条：6px 占位宽度，两侧各 2px 透明边。轨道/角落透明，不显示上下左右箭头。
- **静止时滑块完全不可见。** 只有指针悬停或焦点落在所属面板（组件、AI 面板、任一自有弹窗）内时，才显示 2px、20% 强度的滑块；指针进一步压在滑块本身上时去掉透明边，显示为 6px、40% 强度。
- 占位宽度与显隐无关，恒为 6px：显隐只切换滑块颜色，不得改动槽位尺寸，否则内容宽度会随悬停跳动。
- 显隐条件同时包含 `:hover` 与 `:focus-within`，保证键盘路径可见。不为粗指针环境常驻显示，与插件其他悬停态控件的处理保持一致。
- 使用既有 WebKit 样式保证精确像素，不添加会覆盖它的 `scrollbar-width: thin` 或 `scrollbar-color`。弹窗挂载在工作台根节点外，必须把弹窗类显式加进全部宿主清单——槽位、轨道/角、按钮、滑块基态、面板显隐、滑块悬停共六段规则各一份，漏一段就会退回 Obsidian 原生滚动条。
- **状态相关的滚动条选择器一律逐个展开，不得用 `:is()` 收拢宿主。** Chromium 匹配 `::-webkit-scrollbar-*` 走独立路径，一旦伪类落在 `:is()` 内（如 `:is(.a, .b):is(:hover) *::-webkit-scrollbar-thumb`）就永不匹配，且不报错——表现正是「滑块藏起来再也不出现」。无状态的段（槽位、轨道、按钮、滑块基态）可以用 `:is()`。
- `:is()` 内也不得出现伪元素：顶层逗号选择器列表不是 forgiving 的，一个无效选择器会让整条规则被静默丢弃。
- 验收手段：`getComputedStyle(el, "::-webkit-scrollbar-thumb")` 的返回值**不反映真实渲染**，`dev:screenshot` 可能返回缓存帧，两者都不能用来验收。可靠办法有两种——量尺寸时临时改槽位宽度、观察滚动容器 `clientWidth` 的差值；验状态时用 `require("electron").remote` 取 webContents，`sendInputEvent` 派发真实 `mouseMove`，再用 `capturePage` 裁剪滚动条那一小条区域截图对比离开／悬停面板／压在滑块上三个状态。

## 自有弹窗通用

- 所有自有弹窗共用一份底材：调色板（`--jd-paper` / `--jd-ink` / `--jd-muted` / `--jd-faint` / `--jd-line` / `--jd-hover` / `--jd-accent`）、`--jd-radius-lg` 圆角、细边与柔和阴影统一定义在 modalEl 上，尺寸与内边距由各弹窗自己声明；内容布局归 contentEl。新增弹窗把 shell 类加进这份共用清单即可，不要另起一套配色。
- 一个弹窗只有一个主表面。表单字段靠留白与低对比标签分区，**不得给每个字段套底色卡片**；列表同理，行默认透明、只用发丝分隔线，悬停做低对比底色变化。
- 每个弹窗只有一个高对比黑白主按钮（`--jd-ink` 底、纸色字），其余一律细描边；次级操作（如「完成并归档」）不得做成第二个实心按钮与主按钮竞争。禁止直接沿用 Obsidian 的 `mod-cta` 强调色。
- 行内操作按钮默认隐藏，仅在所在行 `:hover` 或 `:focus-within` 时出现；不属于任何行的底部操作（如「清空全部归档」）保持常驻并使用描边。
- 覆盖 Obsidian 原生 `button` 时有两个必踩的坑：主题用 **inset `box-shadow`** 画按钮外框，只改 `background` 与 `border` 去不掉，必须显式写 `box-shadow: none`；原生按钮是 **flex 容器**，`text-align: left` 不起作用，需要改 `display: block` 才能左对齐并配合 `text-overflow: ellipsis`。
- 标签色要比标题再弱一档。部分主题把 `--text-muted` 解析成与标题相同的 `#5c5c5c`，直接使用会让层级塌陷，应再降一档透明度。

## Canvas 选择弹窗

- 更换/插入 Canvas 使用单纸面、18px 外圆角、轻搜索框和文件列表；文件名与路径左对齐分两行，使用细分隔，不制作逐行卡片墙，不继承原生按钮固定高度。
- 标题右侧固定放高对比黑白主按钮「＋ 新建 Canvas」，当前画布用小圆点与文字表示；空搜索结果仍保留新建入口。键盘焦点使用细绿色环，深色主题同步反转纸面与主按钮。

## 待办完成与日结单

- 勾选完成不再使用 `text-decoration: line-through`，改为一道穿过标题的马克笔笔触。构成要点：① 笔触画在 `::after` 伪元素上而**不是**标题本身——毛边靠 `mask` 从边缘啃出来，`mask` 挂在标题上会把文字一起啃掉；② 三层错位色带（主笔身 + 上下两道更细、断续位置各异的溢色），两端收到**完全透明**，起笔收笔的渐隐是脱离「几何色块」的关键；③ 两层 mask 相交（`mask-composite: intersect`，相加只会让色带变亮而非啃边）：一层略微偏离垂直的纵向纤维模拟笔头丝缕，一层上下缘柔化；④ 动画只改 `background-size`，溢色层刻意落后于主笔身，像笔尖带出来的墨。
- 笔身要比字还粗才像马克笔，因此**必须压不透明度**（色带峰值不超过约六成），否则会盖住文字。粗细与透明度是一对互相约束的参数，调其中一个就要复核另一个。
- 划线长度必须贴合文案：承载标题的元素要用 `flex: 0 1 auto`（不增长只收缩），若用 `flex: 1 1 auto` 撑满剩余空间，笔触会一路画到文字之外。标题不再撑满后有两处连带影响必须一起处理：右侧的日期等元素改用 `margin-left: auto` 顶回右边；承载行内容的原生 `<button>` 必须显式写 `justify-content: flex-start`——主题把它设成了 `center`，标题撑满时看不出来，一旦按内容宽度排布就会整行居中（`text-align` 对 flex 容器无效）。
- 完成态文字保持 `--jd-muted`，不再额外压暗（曾试过再弱两档，Jam 要求撤销）。若日后又要调这里，记住标题被 `.jam-deck-root :is(…, .jam-deck-task-title, …)` 钉在固定的 `--jd-heading` 上，只改外层容器的 `color` 无效，必须在完成态的标题选择器上显式覆盖。
- 勾选框与笔触是同一拍动效：方框由品牌绿灌满、同时用 `box-shadow` 从 0 扩到 7px 再散掉做一圈波纹，勾本身延迟约 90ms 淡入。只用 `background-color` / `box-shadow` / `opacity`，不需要 transform 例外。与笔触共用 `.is-striking` 一次性标记，保证只在刚勾上的那一下播放。
- 笔触动画必须只对「刚被勾选的那一条」播放。列表在每次 `renderAllViews` 时整体重建，若把动画绑在 `.is-completed` 上，打开任意弹窗都会让全部已完成项重播。实现上由插件记一个一次性标记，渲染时消费掉，与时钟翻牌「只对发生变化的数字执行」同一原则。
- 「归档」是当天结算入口，「详情」才是查看历史归档。归档一次处理全部已完成项，共用分阶段事务、同篇笔记合并原子写入；批次开始/结束各刷新一次，通知汇总一次，不逐条重绘整页或堆叠成功提示。失败的留在已完成态并提示可重试，不做静默丢弃；小票结算动画只在全部成功后播放。
- 日结单（小票）**不使用**自有弹窗的共用纸面底材：热敏纸是窄长条且有齿边，自带独立表面，只共用极细滚动条那一组规则。纸面使用等宽字体与 `tabular-nums`，虚线分隔，齿边由 `-webkit-mask` 从纸面本身挖出而不是叠加装饰层。条形码是无数据的装饰条纹。
- **日结单动效是限定例外**：与时钟翻牌、Canvas FLIP 同级，允许使用 `clip-path` + `transform`。编排取自 randyloop 原视频（逐帧实测）与 Spatial 的弹层手感：
  - 打开：遮罩淡入；打印口以约 8% 过冲弹出（Spatial 新建卡片即此曲线）；小票从打印口下沿**整体滑出**、页脚先露，分四段送纸、段间短停，读作热敏头逐块打印。`clip-path` 的上内缩与 `translateY` 同步，可见上沿始终钉在打印口下。每次打开只播一次，归档失败后的重绘不重播。
  - 确认归档（仅全部成功时）：一条时间轴——盖「已结算」章、纸面随之一震 → 停一拍 → 拽两下（齿孔先连着弹回，第二下撕开）→ 撕下后绕抓握点钟摆式甩向一侧再回摆 → 向右上甩出淡出 → 弹窗收起。归档后不再吐第二张票。
  - 关闭（Esc、点遮罩、结算结束）一律先缩小淡出再移除，比入场更快。Obsidian 的 `close()` 会同步摘掉容器，因此由弹窗自己延后真正关闭。
  - 时长只写在 `styles.css`，JS 从计算样式读回再等待，不另存常量。纸面齿边是 mask 挖的，mask 会连带裁掉自身的 `box-shadow`，所以纸面阴影由外层 `filter: drop-shadow` 投在挖好的轮廓上。
  - 除打印口、纸面、印章与弹窗进出外，小票内部不得再增加动效。
  - 外壳是透明的，但 Obsidian 的 `.modal-container.mod-dim .modal`（0,3,0）会给它画 `--shadow-l`；纸面平时盖住它看不出，一到送纸中途或甩走后就露出一圈矩形阴影。外壳的 `box-shadow: none` 必须用容器类提到 (0,4,0)。测试页若不带 Obsidian 原生弹窗规则，查不出这类问题。
- 关掉动效走插件自己的「动画效果」开关，不查系统 `prefers-reduced-motion`（只有壁纸/光学模块例外）。工作台内的动画由 `.jam-deck-root.jam-deck-no-motion *` 统一归零；自有弹窗挂在根节点之外，够不着那条规则，必须在 JS 里按设置决定是否挂动画类。

## 时钟

- 倒计时放在日期下方并与时钟共用一个组件表面，不增加第二张卡片。
- 启停使用原生复选框与短状态文字；时长输入固定拆成“时 : 分 : 秒”三个两位数字格，使用等宽数字和低对比独立底板。
- 运行状态将输入切换为固定六位 `HH:MM:SS` 独立数字翻牌；牌面高度保持 26–30px，并在组件右侧和底部留出不小于 4px 的安全距离。
- 浅色牌面使用纸灰层次与深色数字，暗色牌面使用炭灰层次与浅色数字；禁止写死同一套深色牌面跨主题使用。
- 翻牌是时钟模块允许使用短 transform 动画的限定例外：只对发生变化的数字执行，持续 280ms，并必须响应 `prefers-reduced-motion`。
- 水平空间不足时优先保留启停命中区与完整时间，不通过缩小字号破坏可读性。

## 灵动岛

- 独立顶栏随皮肤使用纸面或玻璃，沿用细边和品牌绿焦点，不另造厚卡片或大面积荧光底。按 Jam 选择持续采样桌面和下方应用，排除灵动岛自身，使用工作台同款 Hyalite 边缘折射；共用既有 0–16 模糊和均衡/轻盈设置，不新增参数。没有 40% 白色填色，文字随系统明暗主题。
- 玻璃展开窗口仅占可见的 72px 高表面，沿用平顶与左右下角 31px 圆角。小画布位于控件之下、不接收输入；角外必须完全透底，不允许另有矩形底材。采样最高 30fps、无音频、不落盘或上传；收起停止采样并切为 10px 细条，退出、卸载或采样异常清理并恢复工作台。Windows 已实机验证；Mac Apple Silicon 编译通过，M5 屏幕录制权限、裁切、折射和性能仍需实机验收。
- 单页布局：绿点「灵动」、剪贴板芯片、紧凑倒计时、「工作台」；芯片高 54px，左右侧槽 100px，控件等距，不堆第二分页或 AI 表单。
- 折叠态只保留居中约 70% 宽、10px 高的白条窗口；透明区点击穿透，不得挡住下方浏览器标签或其他窗口。悬停白条才展开。
- 展开后离开判定以可见胶囊为准，不含透明阴影垫；折叠延时由设置「灵动岛折叠延时」配置（0.3–3 秒，默认 1 秒）。

## 剪贴板

- 窄栏保持单列 Polaroid；组件宽度达到 360px 后自动多列。
- 图片使用自然比例或 `object-fit: contain`，禁止关键内容裁切。
- 可拖拽卡片根和伪元素不使用 transform；错层位于内部预留区域且不接收 pointer event。
- 操作条在 hover、focus、focus-within 和粗指针环境可见。
- 键盘顺序：卡片 → 复制 → 删除 → 下一卡片。
- 复制与删除只在卡片 hover、focus-visible 或 focus-within 时出现；不得因为系统同时存在触控屏、数位板或粗指针设备而常驻。

## 快捷方式

- 快捷方式图标与名称间距 10px，列间距 12px、行间距 16px；整组水平居中，只有单排时垂直居中，两排及以上贴内容区顶部。列宽随全局字号增长；高度不足时从顶部滚动，保持原有排序和打开交互。
- 拖拽排序不增加常驻手柄或新的卡片底板；卡片本身保持可拖拽。
- 删除只在编辑模式出现，浏览态不显示删除。
- 本地应用/文件夹/快捷方式在库内保存一份 `.lnk` 记录；原文件被挪走后仍用这份记录打开。网页快捷方式仍只存 URL。
- 插入位置只使用 1–2px 低对比细线，拖动项仅降低少量透明度，避免网格抖动和厚占位块。
- 网页图标使用域名首字或地球图标，落在六个可区分的低饱和色槽之一（雾蓝、鼠尾草、丁香、沙杏、绯陶、青瓷），字色取同色相深色；荧光绿不作为常驻网站品牌色。无图标本地应用使用 Lucide app-window 图标兜底，不使用 emoji。
- 编辑弹窗使用单纸面、轻分隔、圆角操作按钮与黑白主按钮，直接展示真实图标预览，并接入统一极细滚动条。默认图标与字符封面由轻量二选一控件切换；字符以完整字素为单位（含汉字、组合 emoji），背景允许用户指定两个渐变端点（默认杏色→藕粉浅渐变），文字随配色自动选择深浅。
- 快捷方式弹窗按关联排版：预览在左、外观设置在右；下一排短名称与长链接并列，底部提示与操作按钮同排居中对齐。隐藏未使用的原生空标题栏，外边距与主要分区间距 24px，外观内部间距 20px，不以压缩总高度牺牲内容呼吸感。窄窗按内容宽度换行，不把名称扩成整行长字段；焦点环保持完整可见。
- 文件夹默认复用 Canvas 的 SVG 底板、叠纸、半透明前片及右下双凹槽，使用快捷方式专属的六种柔和配色（暖灰、珊瑚、藕粉、杏色、鼠尾草、雾蓝；旧 Canvas 六色自动映射保持色相）；不套额外方形卡片。封面编辑保留原打开目标与排序，取消不落盘，保存失败保留输入。
- 键盘焦点沿用现有绿色细环，排序结果进入视觉隐藏的 `aria-live`，不在界面堆叠说明文案。

## Canvas

默认只调整 Jam Deck 自有宿主外壳，禁止用泛化选择器覆盖原生 Canvas 内部节点、pointer-events、层级和工具条。用户明确要求的图片节点、底部卡片菜单、画笔浮层和缩放簇全屏按钮例外必须全部以 `.jam-deck-canvas-leaf` 开头；图片规则还要同时限定 `.media-embed > img`，不得影响普通 Canvas 标签页或非图片节点。

- 工作台顶栏在「映画」旁提供无底文字「设置」，直接打开 Jam Deck 设置页。内嵌 Canvas 底部卡片工具栏在 5 秒无操作后隐藏，移动、点击、滚动、输入或键盘操作即时恢复；拖拽按住和工具栏键盘焦点期间保持可用。只切显隐、不移动或销毁原生工具栏，不影响右侧缩放簇、选区菜单及 Canvas 数据；纸面/玻璃共用，控制器随 Canvas 销毁释放监听与计时器。
- 嵌入 Canvas 支持 Ctrl+Z / Ctrl+Y 走原生画布历史（画笔模式仍只撤销笔迹）；Ctrl+V 把剪贴板图片落到视口中心，复用拖入附件路径。无图时把文本 / 链接 / Canvas 片段交给原生粘贴。
- 底部缩放簇增加全屏按钮：原生 `clickable-icon` + maximize/minimize，不加厚底板。进入后把工作台根挂到窗口铺满，该 canvas-embed 留在网格里占满；隐藏 Obsidian 标题栏、页签栏、ribbon、左右侧栏、状态栏、原生菜单栏、Windows 任务栏与工作台顶栏/其他组件。窗口走系统全屏以藏任务栏；Esc 或同一按钮退出并还原。不改 F 放映，放映仍不得进入系统全屏。
- 选中图片、GIF 或视频后，原生 `.canvas-menu` 悬浮工具栏增加导出：原生 `clickable-icon` + download，不加厚底板。单选与多选均可；只复制当前 selection 里的媒体附件到用户选择的系统目录。不进入系统全屏，也不改 AI 单选与 F 放映。
- 图片节点保持边到边铺满并隐藏文件名，圆角必须直接复用快捷方式图标的 `--jd-radius-sm`；Canvas 分组使用下一层级 `--jd-radius-md`，不得另造近似数值。令牌的具体像素值只以 `styles.css` 为准，本文件不重复写数值。
- 图片、Canvas 文本和 Markdown 笔记在按住（pointerdown）时立即悬浮：仅柔和多层阴影与降至 50% 透明度，不做位移与缩放；静止混合堆叠保留轻阴影。重叠严格超过较小节点面积 50% 时形成错位堆叠。
- 堆叠单击展开使用短生命周期屏幕卡片：图片、文本与笔记从真实位置出发并按各自 Canvas 比例自适应排版；被归一化的大图按首次原 Canvas 尺寸展开。文本/笔记展开尺寸单独取视觉平衡纸面，不沿用 Canvas 节点框：有图时约等于同排图片高度的 90%、宽度约 42%，无图时固定 220×260，偏大的文本卡同样收到这个尺寸；真实节点世界尺寸不变。
- 展开后的 Canvas 文本统一使用 12px 屏幕字号；必须反向抵消 FLIP 卡片缩放，禁止继承原生 Canvas 的缩放补偿后随视口缩小而放大。
- 展开文本使用固定 16px 屏幕内边距，并重置阅读宽度、自动居中和内部多层 padding。展开的图片/GIF、文本与笔记卡片圆角必须与 F 放映相同，复用 `--jd-canvas-image-radius`。
- 每张预览卡必须先以对应真实节点的屏幕矩形和 `scale(1)` 提交起始帧，再进入目标排版；展开期间真实节点完全隐藏，收回动画完成后才恢复，禁止保留静止底图破坏“整叠散开”的连续感。
- 旧式自由堆叠的最终排版及其 64px 影响区内，其他 Canvas 节点可在蒙版下向外让位；explicit folder 使用窄避让，只推开被展开卡片实际覆盖的零散节点，并在让位后保留 20px 间距；跳过隐藏的文件夹成员，禁止重新引入全画布无关节点的合成动画。
- 聚焦蒙版必须高于图片节点和全部原生 Canvas 控件，并真正阻断 pointer、wheel、contextmenu 与键盘快捷键；堆叠展开覆盖层只有“点击收起”和 `Esc` 两个操作，不显示额外关闭按钮。
- 原生 Canvas 聚焦在 Jam Deck 工作台内改为放映：蒙版挂在工作台根上并盖住 AI 按钮，内容在 48px 安全边距内居中。文本/笔记读取节点正文，使用 `--jd-paper`、纸面颗粒与左侧 36px / 底部 32px 边距；滚动条相对正文右移 10px。溢出正文在底部用渐隐蒙版收住，不要硬切。视频空格播放；点击进度条只seek，不留下控件焦点环，也不用方向键控进度。`F` 在放映中一律关闭，不得进入原生全屏。独立节点若有连线，方向键沿连线翻页：A 向右连 B 时，放映 A 按 `→` 到 B；上下连线对应上下键。连线方向以 `fromSide`/`toSide` 为准。文件夹展开仍用左右按成员顺序翻页。
- 文件夹或堆叠展开后，单击图片、GIF、文本与笔记进入同一套放映层，不回到原生编辑、不另开标签。文件夹展开放映在左右给出圆形箭头，可翻到下一张。连线放映在有邻居的方向给出同样的圆形箭头（含上下），点击与方向键走同一条 hop；翻页后箭头随当前节点邻居更新。无连线且非文件夹多成员时不出现箭头。翻页沿运动方向做 36px 位移 + 渐隐，180ms，不要缩放。不得因为画布 ResizeObserver 收掉放映。关闭与翻页按钮默认白底 15%，悬停 80%，按下 100%；必须压过 Obsidian 原生 button 底色，默认态不得看起来像实心白圆。放映层用隐藏标题命名，禁止给全屏遮罩加 `aria-label`，避免 Obsidian tooltip 盖住底部箭头。
- 展开使用 300ms `cubic-bezier(.22,1,.36,1)`、18ms 错峰且最多 72ms；再次单击堆叠或单击空白后用 260ms 反向收拢。卡片按下后鼠标/笔 6px、触控 10px 以内视为点击并进入放映；越过阈值则以柔和阴影抬起并拖出堆叠。拖动途中不改变世界坐标，松手只产生一次落点提交。
- 文件夹壳体以 Figma `NZS4 / 102:6` 为几何基准：200×150 外壳必须依次表现完整 SVG 底板、真实代表图、x=0/y=50 的半透磨砂前片、低对比数量/“编组”文字与右下双凹槽，不增加独立遮罩层；数量与名称保持 Figma 内部间距，并作为一组在原基线上下移 20px；装饰层全部 `pointer-events:none`，不得用矩形底色或矩形阴影填平 SVG 的透明圆角。折叠壳体在任意 Canvas 缩放下必须保持可见：工具栏重叠不得隐藏纸面；磨砂滤镜失败或高倍缩放时允许关掉 blur，但前片色块、底板和文案仍在。
- 底板容器为 x=0/y=8.21/w=200/h=141.79，但导出 SVG 保持 240×181.79 原尺寸及负边距溢出，不能压缩为容器 100%；前片为 200×100 且四角统一 10px。
- 折叠预览最多呈现 4 个真实代表成员：1 个代表居中，2–4 个按设计节点固定双列位置和约 -4.6°/2°/3°/-2° 旋转；图片节点、容器、媒体层和图片本体逐层复用 10px 圆角并裁切，文本保持自身比例，不创建常驻 clone。非代表成员隐藏而非删除，代表图必须严格夹在底板与前片之间。
- 文件夹悬停操作条使用轻量图标：颜色、原位展开、取消编组、重命名；颜色弹层保留 6 个低饱和 radio。壳体点击仍进入散开预览：悬停前片翻开 18°，完整开合端点为 48°；前片翻开后卡片散开，关闭时卡片先用既有 260ms 回位、再由前片合拢；拖出、取消、Esc 和空白点击进入同一清理路径。减少动态效果时直接落到最终状态。
- 普通章节使用原生 Canvas 分组框；只有收起文件夹自身的框、成员和关联连线在 Jam Deck 隐藏。原位展开恢复原生框与可编辑内容，不留第二个浮动控制框；选中原生分组时，原生悬浮工具栏提供「收起为文件夹」。外层章节可包住多个文件夹；包含内层分组的章节保留为框，避免折叠隐藏整个章节层级。
- 原生 Canvas 的标准坐标、尺寸和连线始终描述展开内容；折叠壳体为独立展示位置。拖动壳体只做整体平移，散开预览不改布局；只有明确网格排列与拖出成员才改变对应布局。
- Canvas 底部菜单使用 18px 大圆角连续底板、46px 命中区与柔和双层阴影，保持原生图标和操作顺序。
- 画笔面板在底部菜单上方悬浮，使用 16px 圆角、紧凑分组和低对比分隔；颜色以小圆点呈现，绿色仅用于激活/完成等短促状态。标注统一使用所选固定粗细，不以压感制造额外视觉层级。
- 窄宽度优先换行或折叠分组，不能缩小主要按钮的命中区；焦点环必须清晰，触控与键盘路径不可被装饰层阻断。

## 工作台浏览间距

- AI 助手悬浮按钮的位置必须随 Jam Deck 根区域尺寸实时夹在可视范围内；窗口缩小、换显示器、分栏变化或插件热重载都不得让持久坐标落到裁切区外。聊天窗继续贴近按钮，并独立限制在工作台边界内。
- AI 弹窗保持一个主表面，以轻量文字页签承载“AI 助手 / 本地工作区”；助手页维持紧凑对话尺寸，本地网页页可扩大但必须继续受工作台边界限制。页签只使用细底线、文字层级与焦点环，不增加第二层厚卡片或大面积强调色。
- 本地工作区页顶部只保留目标路径、连接状态与必要的手动选择提示；嵌入网页占据其余空间。宿主不得以视觉文案伪装已经控制网页当前会话，服务离线时使用短错误文字与轻量重试按钮。

### 紧凑水印态

- 每种组件独立记录最小完整显示阈值；宽度或高度任一方向低于阈值时，不缩字、不压缩正文，改为只显示标题栏图标水印。
- 水印居中、低对比、无额外卡片和描边，底面继续使用工作台主题主表面；暗色主题不得写死白底。
- 水印按钮保留清晰键盘焦点，点击后只补足低于该类型阈值的方向，已经足够大的宽度或高度保持不变。恢复优先移动与下方/右侧组件的共享边界并压缩邻居，无法满足时才回退到整块自动让位；不得因邻居占位而直接误报无空间。图标外空白仍可承担布局拖动，图标本身不得误触发拖动或 sash。
- 紧凑组件正文保持热挂载但视觉隐藏，保证间距圆点拖动跨过完整显示阈值时同帧恢复真实内容；松手只提交布局，不承担首次渲染。减少动态效果时取消过渡但保留状态切换。
- 编辑态与浏览态共用间距绿色圆点调整相邻尺寸，不再给组件增加右下角斜杠手柄。

- 编辑态与非编辑态下，组件贴齐交界的节点默认不可见；鼠标靠近约 18px 时才出现 9px 小圆点，禁止常驻手柄条或厚分割条。
- 竖缝用左右光标，横缝用上下光标，十字交点用移动光标；激活态可用品牌绿点，常态保持低对比墨色。
- 单个组件真实右下角的圆点只控制该组件宽高；右/底外边界中段圆点才统一收缩所有贴边组件，普通内部十字点仍控制四周间距。三类圆点沿用同一视觉，但交互范围必须明确；不得另加外框或常驻缩放手柄。
- 拖动只改变缝两侧面积，不引入额外占位块、荧光底或大面积蒙版。

## 工作台编辑布局

- 编辑拖动中的组件整块悬浮抬起并带柔和阴影，拖动过程不算碰撞。
- 空白区域能够容纳组件原尺寸时，优先显示同尺寸 slot 预览并允许直接放置；保持抓取点、不改尺寸、不移动无关组件。只有原尺寸矩形放不下时才进入填充槽或推挤逻辑。
- 新增组件无默认尺寸或最小完整尺寸空位时，优先在当前最大面积且可压缩的组件右侧/下方切出最小完整矩形；仅压缩该组件，绿色仍只用于短暂结果提示，不增加常驻高亮。
- 可填充空隙用独立 slot 矩形预览：绿色渐变描边 + 极浅绿透明填充，禁止厚占位块或大面积荧光。
- 纵缝矩形使用邻格统一宽度并填满空隙高度；横缝矩形使用邻格统一高度并填满空隙宽度。
- 没有可填充空隙时改为在相邻两端亮浅品牌绿渐变（约 30% 透明、不超过边长 30%/40px），表示将推挤插入。
- 拖动时底部显示白色渐变提示条与一行说明文字（按住 Shift 可延伸填充到画布边缘）；按住 Shift 后提示立即消失，松手后一并收起。禁止做成厚卡片或荧光底板。
- `prefers-reduced-motion` 取消非拖动项过渡，悬浮阴影仍可保留静态抬起感。

## Game Deck（独立插件）

3D 侧不套用工作台的墨色规范，但 2D 编辑态必须与 Jam Deck 同语言：

- 草原走 Tiny Glade 的明亮低饱和路线：暖阳、天空渐变、柔和阴影、圆润几何；不加描边、不加发光轮廓。
- 选中与悬停只用地面浅绿光晕、轻微抬起和名牌，禁止荧光包围盒或整块变色。
- 编辑态覆盖层沿用细边、8px 圆角、白底卡片和小圆点：矩形填充仍是绿色渐变描边 + 极浅填充，零缝隙推挤仍是两端浅绿渐变，底部仍是白色渐变的 Shift 提示条。
- 缝隙圆点常态半透明，悬停或激活才实心放大；不出现常驻手柄条。
- 编辑态开启时 3D 停帧，避免半透明覆盖层之上仍持续渲染。

## 字幕墙

- 新建默认 10×9 格，完整显示下限 6×8 格；小窗优先保留至少两行可读正文，正常正文 17px，操作按钮命中区维持 32px。
- 工具栏与正文之间采用 4px 间距，去除大段空白；空闲跟读不显示固定底部说明，实际听到的语音用一行呈现，超长省略并可悬停查看全文。

## 性能

- 不复制图片制造常驻底板；仅允许堆叠点击展开期间创建短生命周期的图片预览副本，并在收起后立即销毁。
- Canvas 聚焦蒙版只使用半透明纸面 wash，不使用全屏 `backdrop-filter`；文件夹前片的小面积固定磨砂仍保留。
- 不动画 blur 半径或饱和度，不使用全屏重型滤镜；Figma 文件夹前片允许固定 `blur(16px) saturate(180%)` 的小面积 backdrop-filter，开合只动画 transform/opacity。
- Canvas 堆叠的短生命周期预览可额外使用 transform 完成 FLIP 位移动画；悬浮工具栏与弹层显隐允许上文登记的轻微缩放回弹，Canvas 底栏以独立 `scale` 保留原生定位；其他模块仍只使用 opacity、border、background 和 shadow。工作台编辑拖动的短 opacity/border 过渡、以及日结单的吐纸、盖章撕票与弹窗进出是限定例外。动效开关一律走插件自己的「动画效果」设置，**不查系统 `prefers-reduced-motion`**——只有壁纸/光学模块会读系统设置，这条由 `tests/jam-deck-test.js` 的断言守着。
- `prefers-reduced-motion` 取消 FLIP 和推挤的过渡过程，但仍直接呈现最终展开与让位布局，不能因此关闭功能。
