Jam Deck 1.0.0 正式发布：把时钟、待办、日历、剪贴板、快捷方式、音乐、Canvas 与 AI 助手放进同一个 Obsidian 工作台。

## 相比 v0.32.6 的更新

- **更易阅读**：界面字号小 / 中 / 大，现有用户保留小档，新安装默认中档；字幕与跟读支持独立字号。自有标题统一为 `#5c5c5c`。
- **快捷方式自定义**：单字符或 emoji 封面、双色渐变、实时预览、多彩文件夹与新的默认图标配色。编辑弹窗重新排版；图标和名称间距加大，单排居中、多排顶部对齐。
- **Canvas 入口改善**：文件选择器采用清晰的名称/路径层级与极细滚动条，加入醒目的「新建 Canvas」按钮。
- **更紧凑的字幕墙**：减小默认尺寸和完整显示门槛，小窗仍可阅读正文；保留本地实时转写、自动翻译、跟读定位和笔记归档。

## 下载与安装

1. 下载 **jam-deck-1.0.0.zip**，将里面的文件直接解压到知识库的 `.obsidian/plugins/jam-deck/`，不要再套一层文件夹。
2. 在 Obsidian 中启用或重新加载 Jam Deck。已有用户请保留原来的 `data.json`。
3. 需要字幕功能时，再下载 **jam-deck-captions-1.0.0.zip**，解压到同一个插件目录，并按[字幕墙安装说明](https://github.com/J4M16/jam-deck/blob/v1.0.0/docs/CAPTION_WALL.md#首次安装)安装语音引擎。

基础 ZIP 包含图形资源，推荐手动安装使用。另附 `main.js`、`styles.css`、`manifest.json` 标准三件套。字幕扩展按需下载，两个 ZIP 均不包含个人运行数据、API Key、Python 运行时或语音模型。

## 验证与平台范围

- `npm run verify` 全部通过；五个发行文件已校验，ZIP 内文件与源码逐一一致。
- 本轮界面改动已在 Windows Obsidian 中检查，包括字号切换、窄窗排版、单/多排切换和快捷方式编辑。
- 仅支持桌面端。macOS Apple Silicon（M 系列）已纳入适配，但 **M5 首次权限、真实采音及完整交互尚未实机验收**；音乐组件依赖 Windows 系统媒体会话，Mac 不可用。
- 灵动岛图片拖往外部聊天框的接收效果仍待实测。Linux 未完整验证，音乐与字幕录音不可用。

工具：Codex；处理模型签名：具体模型标识不可见（发布执行与验证）。
