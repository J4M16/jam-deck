# Liquid Glass 皮肤

在 **设置 → Jam Deck → 外观 → 界面皮肤** 中选择 `Liquid Glass · 玻璃`；`Spatial · 纸面` 保留原外观。1.1.0 新增，默认仍为 Spatial。

## 使用

- 1.1.4 顶栏新增纯文字「映画」，直接选择背景图片或视频，与设置页共用导入流程；纸面下成功导入后切到玻璃，取消不改变皮肤或背景。
- 1.1.5 灵动岛改为无桌面磨砂的清透玻璃，直接透出桌面和下方应用，保留原来的平顶、31px 下圆角以及轻底色、高光和细边。工作台的 0–16 模糊滑块不影响它；文字随系统明暗配色，普通操作不叠第二层底板。
- 组件外框、工作台工具栏、AI 浮层、按钮及自有弹窗共享通透底色、方向高光和细边。内容不做截图或替换，Canvas 节点和嵌入网页保留自己的内容样式。
- 均衡档使用有限的真实边缘折射；轻盈档关闭 SVG 折射，保留轻磨砂、高光与透明表面。
- 1.1.1 新增「玻璃模糊」0–16，默认 4。拖动实时预览，松手保存；Canvas 大表面使用一半强度。调节只更新滤镜参数，复用几何贴图和背景媒体。
- 纸面/玻璃都可独立隐藏 Obsidian 侧栏与顶栏。只对活动工作台生效，点击内嵌 Canvas 仍保持；切普通笔记恢复，侧栏原有展开状态不变。隐藏顶栏时最小化、最大化、关闭按钮一并隐藏，先点工作台左上角「恢复界面」才显示。
- 选择本机 JPG / JPEG / PNG / WebP / AVIF 图片，或 MP4 / WebM 视频。媒体导入 `attachments/jam-deck-backgrounds`，设置只记录库内相对路径。随库同步后，Windows/macOS 不需要重写盘符。
- 视频静音循环，推荐 1080p、30 fps。工作台不可见、进入灵动岛、手动暂停、关闭插件动画或系统减少动态效果时暂停；背景被替换、切回纸面或关闭工作台时释放媒体源。
- 背景压暗范围为 0–70%。恢复默认使用内置 CSS 极光渐变，保留已导入的附件，避免误删媒体。
- 1.1.2 自动读取整张壁纸平均亮度，深背景使用浅色文字、亮背景使用深色文字；背景压暗参与判断。文字、图标、控件、Canvas 工具栏和空状态一起适配，原生 Canvas 节点保持自己的配色；弹窗继续按 Obsidian 主题匹配其独立底材。
- 普通操作取消重复底板与阴影，待办悬停轻叠色，删除按钮不再有白方块；倒计时输入与翻牌、自有表单统一透明层次，选中态使用细线，保留键盘焦点。待办不再重复弹出整条标题的黑色提示。
- 皮肤与背景原地更新，不调用工作台整体重绘，不中断 Canvas、AI 和字幕的现有节点。

## 方案取舍

采用 [Hyalite 0.5.0](https://github.com/VII-Cae/hyalite--liquid-glass/tree/b9f27192a7256bf5295bf027b582b86864f9b59d)，MIT，零运行依赖。其 SDF 镜片贴图通过 SVG `feDisplacementMap` 对真实 DOM 背景进行屏幕空间折射，文字与输入控件本身不扭曲。它不是苹果私有原生材质的逐像素复刻。

比较了 [Deepika](https://github.com/deepika-builds/liquid-glass)、[xcyberpunkx0](https://github.com/xcyberpunkx0/liquid-glass) 和 [ybouane](https://github.com/ybouane/liquidglass)。前两者更轻或提供画质档位；后者借助 DOM 截图和 WebGL。没有找到足够证据证明它们在 Jam Deck 多组件、动态 Canvas 的场景下全面优于 Hyalite，因此保留用户给定方案的几何与缓存核心，不引入 React 或 DOM 截图体系。

Hyalite 保留在 `main.js` 的独立工厂函数中，完整 MIT 许可随标准三件套分发，不增加需要用户另装的脚本。相对上游的适配：

- 根据 `ownerDocument.defaultView` 建立实例，多个窗口的滤镜 ID 隔离。
- 增加完整销毁：观察器、定时器、SVG host 和贴图缓存都释放。
- 闲置贴图缓存上限从 24 降为 8。
- 控制器管理表面预算，不使用全页 DOM MutationObserver 扫描原生 Canvas。

1.1.1 对照 [Apple 的 Liquid Glass 说明](https://developer.apple.com/videos/play/wwdc2025/219/) 减少玻璃上再次叠玻璃：顶部按钮按 Jam 要求使用无底纯文字，右侧工具栏只给独立功能组底色，分割线与外沿同强度。高光由硬白圈改为低强度方向高光；Hyalite 参数采用 `bevel:18, thickness:40, slope:1.8, rim:0.22, shade:0.14, edge:0`，增强位移而非提亮描边。这是 Jam Deck 的视觉参数，不是苹果的材质参数。

## 性能约束

- 灵动岛使用透明窗口与 CSS 清透表面，移除原生 acrylic / vibrancy 及窗口区域拼接，不捕获屏幕、不复制壁纸视频、不增加后台进程。只在皮肤和展开/收起状态变化时同步窗口尺寸，倒计时刷新不重复设置尺寸。
- 每个工作台最多 4 个折射表面；单面不超过 180,000 CSS 像素，总计不超过 360,000 CSS 像素。优先工作台与 Canvas 底部工具栏，再是 AI 和小组件；Canvas 大板不占用折射预算。
- 单通道位移，无 RGB 色散；`sat: 1` 跳过环带饱和度分支。尺寸变化后 180ms 合并重建，不动画模糊半径。
- 主表面模糊由用户设置，默认 4px，两种质量档共享；Canvas 大面积底材为半强度，默认 2px。底材是不可交互的独立层，不占用布局拖拽的伪元素，也不会截断内部工具栏的背景取样。普通按钮使用父表面已采样的背景，不逐按钮建立滤镜。
- 只有一份背景媒体；桌面导入使用文件系统复制，不把整段视频读成 base64。没有自建持续动画循环。
- 亮度图片读取一次，视频每秒一次，先缩至 32×18 再读取像素，不逐帧处理；使用不请求频繁读取的 Canvas 路径，避免实测更慢的 CPU 取样路径。缓存用于压暗调整；透明像素按内置背景的代表亮度合成，失败媒体隐藏后重新按默认背景配色。相对亮度低于 0.24 切浅字、高于 0.32 切深字，中间保留当前配色；这是整体取样，不保证每个局部内容区域的对比度。
- 缓存降低贴图生成成本，不会消除 backdrop-filter 的合成成本。多个工作台、4K/高帧率视频与高 DPI 会增加负担；不能把上述预算等同于帧率保证。
